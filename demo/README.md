# AI Health Navigator Demo

This demo showcases the AI Health Navigator's Enhanced Agentic AI capabilities using realistic mock data.

## 🚀 Quick Start

1. **Open the demo**: Simply open `index.html` in your web browser
2. **View the data**: The demo will automatically load and display data from all CSV files
3. **Explore features**: Navigate through different sections to see the AI system in action

## 🔧 Technical Details

### **Data Sources**
The demo loads data from 5 CSV files in the `mock-data/` directory:

1. **`patients.csv`** - Patient demographics and medical history
2. **`symptoms.csv`** - Symptom descriptions and severity
3. **`healthcare_providers.csv`** - Provider information and specialties
4. **`agent_conclusions.csv`** - AI agent analysis results
5. **`ai_analysis_results.csv`** - Comprehensive medical assessments

### **Technology Stack**
- **HTML5** - Modern semantic markup
- **TailwindCSS** - Utility-first CSS framework
- **Chart.js** - Interactive data visualization
- **Vanilla JavaScript** - CSV parsing and data management
- **Font Awesome** - Professional icons

### **Key Features**
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Real-time Data Loading** - Automatic CSV parsing and display
- **Interactive Charts** - Hover effects and dynamic updates
- **Professional UI** - Medical-grade interface design
- **Error Handling** - Graceful fallbacks for missing data
